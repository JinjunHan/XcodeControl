# XcodeControl v1.0.3_b4

发布日期：2026 年 8 月 17 日

## 更新内容

- 浮窗状态行新增当前 Git 分支显示，与运行状态同行并保持右侧对齐。
- 点击分支名称即可浏览和切换本地分支，支持 `feature/foo/bar` 等多级分支结构。
- 新增 Git worktree 识别与切换，可直接激活已管理的 worktree 项目。
- 项目管理中新增 Worktree 项目同步，并展示每个项目对应的分支和 worktree 状态。
- 日志入口调整为独立一行，展开日志时仍可查看和操作当前分支。

## 改进与修复

- 非 Git 项目会自动隐藏分支入口，不会产生错误提示。
- 修复 `foo` 与 `foo/bar` 同时存在时的分支树显示和切换问题。
- 改进失效 worktree、软链接、空格和中文路径的识别与错误处理。
- Git 操作失败时保留分支面板，并可从日志中查看完整错误详情。
- 改进多工程仓库中的 worktree 工程匹配，避免错误导入无关项目。
