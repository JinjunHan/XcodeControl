# XcodeControl v1.0.4_b5

发布日期：2026 年 9 月 1 日

## 新增功能

- 项目菜单新增 Swift Package 工具，可按 `Package.resolved` 恢复依赖、联网重新解析依赖，以及清理当前项目的 Package 缓存。
- Swift Package 缓存清理仅作用于当前项目，不会删除其他项目或全局 SwiftPM 缓存。
- 设置中新增 Git 分支状态显示开关，可按需隐藏浮窗中的当前分支信息。

## 改进与修复

- 优化 Scheme 加载：优先直接读取工程中的 Shared Scheme，不再因为网络不可用或 Package 缓存异常而长时间卡住。
- 改进 Swift Package 错误提示，可识别网络不可达、锁定版本缺失和本地 Git 缓存损坏，并给出对应修复建议。
- 改进命令取消与超时清理，减少 `xcodebuild` 或其子进程残留在后台的情况。
- 构建失败卡片支持一键复制错误详情，文件名可以直接选择和复制。
- 日志入口调整为更明确的展开/收起开关，查看构建详情更加方便。
